\# automation-windows



Scripts PowerShell pour automatiser des tâches récurrentes sous Windows.



\## tri-telechargements.ps1

Trie le dossier Téléchargements par type (Images, Documents, Archives, Installeurs, Code).



\- Simulation : `.\\tri-telechargements.ps1 -Simulation`

\- Réel : `.\\tri-telechargements.ps1`

\- Programmé chaque jour à 9h via le Planificateur de tâches.

\- Ne supprime rien : il déplace seulement et ignore les fichiers verrouillés.
